Запусти оркестратор для выполнения сложной задачи.

## Шаг 1 — Архивируй старый контекст

Проверь существует ли `.claude/context/` и есть ли в ней файлы:
- task.md, research-report.md, consilium-report.md, plan.md, execution-report.md, review-result.md

Если файлы есть — автоматически перемести их в `.claude/context/archive/<timestamp>/`
где timestamp = текущие дата и время в формате `2026-06-24_14-30`.
Сообщи коротко: "Заархивировано в .claude/context/archive/2026-06-24_14-30/"

Если файлов нет — молча продолжай.

## Шаг 2 — Создай task.md

Создай директорию `.claude/context/` если не существует.
Создай `.claude/context/task.md` со следующей структурой:

```
# Task

<весь текст который пользователь написал после /mytask>

## HARD RULES
```

Затем прочитай секцию `## HARD RULES` из `CLAUDE.md` и добавь её содержимое в конец файла.

## Шаг 3 — Запусти оркестратор

Запусти агента orchestrator (синхронно, `run_in_background: false`). Передай ему только:
"task.md создан в .claude/context/task.md. Начинай с Research."

## Шаг 4 — Relay-цикл (оркестратор ↔ пользователь)

Оркестратор — сабагент и не может говорить с пользователем напрямую. Его финальное сообщение начинается со статус-маркера. Твоя работа — реле:

| Маркер | Что делать |
|--------|-----------|
| `NEED_ANSWERS` | Покажи вопросы пользователю дословно. Дождись ответов. Продолжи оркестратора через **SendMessage**, передав ответы. |
| `NEED_APPROVE` | Покажи пользователю секции Approach и Risks из plan.md дословно (включая пометку «CONSILIUM skipped», если есть) и путь к плану. Дождись APPROVE или правок. Продолжи через **SendMessage** с вердиктом. |
| `ITERATION_LIMIT` | Покажи сводку неудач. Дождись решения пользователя. Продолжи через **SendMessage** с решением. |
| `DONE` | Покажи финальный отчёт. Цикл завершён. |

Правила реле:
- Всегда продолжай **того же** оркестратора через SendMessage — его контекст (счётчик итераций, стадия) должен сохраниться. Никогда не спавни нового оркестратора посреди задачи.
- Ничего не решай за пользователя: не отвечай на вопросы researcher сам, не давай APPROVE сам.
- Передавай ответы пользователя дословно, без пересказа.
